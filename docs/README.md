# 무한매수법 V4.0 계산기 사용법

## 시작하는 방법

`index.html` 파일을 더블클릭해서 브라우저로 열면 됩니다.  
별도 설치나 서버 실행 없이 바로 사용 가능합니다.

---

## 처음 시작할 때

파일을 처음 열면 아래 화면이 나타납니다.

| 항목 | 설명 |
|------|------|
| 총 자본 | 이 종목에 투자할 전체 금액 (달러) |
| 분할 수 | 40분할(안정) 또는 20분할(공격) |

입력 후 **시작하기** 버튼을 누르면 대시보드로 이동합니다.

> TQQQ와 SOXL은 탭으로 각각 독립 관리됩니다.  
> SOXL을 사용하려면 상단 탭에서 SOXL을 클릭한 뒤 동일하게 초기 설정합니다.

---

## 대시보드 읽는 법

### 상단 상태 바

| 항목 | 의미 |
|------|------|
| 평단가 | 현재까지 매수한 평균 단가 |
| 보유주식 | 현재 보유 중인 주식 수량 |
| 총 자본 | 초기 설정한 전체 자본금 |
| 잔여자본 | 아직 투자하지 않은 남은 금액 |
| T값 진행도 | 전체 분할 중 얼마나 진행됐는지 (막대 그래프) |

리버스모드 진입 시 진행 바가 빨간색으로 바뀝니다.

### 목표가 카드 (3개) — 일반모드

| 카드 | 의미 |
|------|------|
| 🎯 별지점 | 이 가격에서 쿼터매도(1/4 매도)를 시도합니다 |
| 📌 지정가매도 목표 | 이 가격에서 잔여 3/4을 전량 매도합니다 |
| 💵 오늘 매수금액 | 오늘 매수해야 할 금액 (잔여자본 ÷ 남은 분할 수) |

> 별지점은 T값이 높아질수록 점점 낮아집니다.  
> 후반전(T > 분할수/2)에 진입하면 별지점이 **평단보다 낮아지며** 빨간색으로 표시됩니다.  
> 별지점 카드 하단에 **매수점(별지점 − $0.01)** 도 함께 표시됩니다.

## 매수할 때

1. 실제 주문을 먼저 체결합니다 (증권사 앱에서 직접 매수)
2. `① 매수 기록` 탭 클릭
3. **체결된 금액**과 **체결가**를 입력합니다
4. **체결 유형**을 선택합니다
5. **매수 기록하기** 버튼 클릭

입력 즉시 평단가, T값, 별지점, 전량목표가 자동으로 재계산됩니다.

> 반드시 실제 체결 후에 기록하세요.  
> 여기서 입력해도 실제 주문은 나가지 않습니다.

### 매수 금액 입력 기준

- **매수 금액** = 실제 지출 총액 (주수 × 매수가)
- **매수가** = 주당 체결 가격

주가가 높아 예산보다 적게 집행됐다면 실제 지출액을 입력합니다. 남은 금액은 잔여자본에 자동으로 누적됩니다.

### LOC 매수 가이드

포지션이 있는 경우 목표가 카드 아래에 **오늘 LOC 매수 방법** 박스가 표시됩니다.

| 구분 | 주문 방법 |
|------|----------|
| 전반전 (T < 분할수/2) | 별지점 − $0.01 이하에 절반 + 평단 − $0.01 이하에 절반 LOC |
| 후반전 (T ≥ 분할수/2) | 별지점 − $0.01 이하에 전체 금액 LOC (별지점이 평단 아래) |

### 체결 유형 선택

전반전에서는 LOC 주문을 두 가지 가격에 나눠서 겁니다.

| 체결 유형 | 언제 사용 | T 변화 |
|----------|----------|--------|
| 전체 체결 (T +1) | 두 주문 모두 체결됐을 때 (후반전 포함) | T + 1 |
| 절반 체결 (T +0.5) | 별지점 주문만 체결되고 평단 주문은 미체결 | T + 0.5 |

`절반 체결` 선택 시 권장 매수금액이 **1회매수금의 절반**으로 자동 표시됩니다.

## 매도할 때

1. 실제 주문을 먼저 체결합니다 (증권사 앱에서 직접 매도)
2. `② 매도 기록` 탭 클릭
3. 상단에 자동 계산된 **목표가**가 표시됩니다

### 쿼터매도 (보유량의 1/4 매도)

- 현재가가 **별지점**에 도달했을 때 사용
- 실제 체결가를 입력하거나, **비워두면 별지점이 자동으로 사용**됩니다
- **쿼터매도 기록** 버튼 클릭
- T값이 × 0.75로 줄어들고, 별지점이 다시 계산됩니다
- 매도 수량은 `floor(보유량 × 0.25)`로 **온주 내림** 처리됩니다 (소수점 거래 불가 대응)

### 지정가매도 (잔여 3/4 전량 매도 → 사이클 종료)

- 현재가가 **지정가매도 목표**에 도달했을 때 사용
- 실제 체결가를 입력하거나, **비워두면 목표가가 자동으로 사용**됩니다
- **지정가매도 기록** 버튼 클릭
- 손익이 표시되고 사이클이 종료됩니다
- 다음 사이클을 시작하려면 **매수 기록** 탭에서 다시 매수하면 됩니다

## 리버스모드 (원금 소진 후)

T값이 **분할수 − 1**을 초과하면 원금이 소진된 것으로 판단해 자동으로 리버스모드에 진입합니다.

리버스모드는 **무한매도 + 쿼터매수** 조합으로 손절 구간을 통과하는 방식입니다.

### 리버스 배너

화면 상단에 빨간 배너가 표시됩니다. 배너 우측에 **종가를 입력**하면 일반모드 복귀 조건을 실시간으로 확인할 수 있습니다.

- 복귀 조건 충족 시 **일반모드 복귀** 버튼 활성화
- 버튼 클릭 후 다음날부터 일반모드로 재시작

### 리버스 매도 (`② 매도 기록` 탭)

| 항목 | 내용 |
|------|------|
| D1 첫날 | MOC 무조건 매도 (보유량 ÷ 분할수 내림, 별지점 무관) |
| D2 이후 | 별지점(직전 5거래일 종가 평균) 위에서 LOC 매도 |
| 매도 수량 | 매번 직전 보유량 ÷ 분할수 (내림) |

`5거래일 평균 종가`를 직접 입력하면 별지점으로 사용됩니다.

### 리버스 매수 (`① 매수 기록` 탭)

| 항목 | 내용 |
|------|------|
| D1 첫날 | 매수 없음 |
| D2 이후 | 잔금 ÷ 4 만큼 별지점 아래에서 LOC 매수 |

### 리버스모드 T값 계산

| 동작 | 40분할 | 20분할 |
|------|--------|--------|
| 매도 후 | T × 0.95 | T × 0.90 |
| 매수 후 | T + (분할수 − T) × 0.25 | 동일 |

### 일반모드 복귀 조건

| 종목 | 조건 |
|------|------|
| TQQQ | 종가 > 평단 × 0.85 (평단 대비 −15% 초과) |
| SOXL | 종가 > 평단 × 0.80 (평단 대비 −20% 초과) |

복귀 후 T값은 리버스 상태에서 이어집니다.

## 전형적인 하루 흐름

### 일반모드

```
장 시작 전
  → 대시보드 확인 (별지점, 매수점, 지정가매도 목표, 오늘 매수금액)

장 중 (LOC 주문)
  → 전반전: 별지점 아래에 절반 + 평단 아래에 절반 LOC 매수 주문
  → 후반전: 별지점 아래에 전체 금액 LOC 매수 주문
  → 별지점 도달 시: 증권사에서 1/4 LOC 매도 주문

장 마감 후
  → 실제 체결 내역 확인 → 계산기에 기록
```

### 리버스모드

```
장 시작 전
  → 리버스 배너에서 오늘 매도 수량, 5거래일 평균 종가 확인

장 중
  → D1: MOC 매도 주문만 (매수 없음)
  → D2~: 별지점 위 LOC 매도 + 별지점 아래 LOC 매수

장 마감 후
  → 실제 체결 내역 기록 → 종가 입력해서 복귀 조건 확인
```

## 되돌리기

기록 실수를 했을 때 직전 상태로 복원할 수 있습니다.

- 매수/매도 기록 후 거래 내역 우측에 **되돌리기** 버튼이 나타납니다
- 클릭하면 직전 1회 동작이 취소됩니다
- 최대 10단계까지 되돌릴 수 있습니다

## 설정 변경 및 초기화

`설정` 탭에서 자본과 분할 수를 변경하고 초기화할 수 있습니다.

> ⚠️ 초기화하면 현재 사이클과 거래 내역이 모두 삭제됩니다.

### 잔여자본 직접 수정

초기화 없이 잔여자본만 수정할 수 있습니다. T값·평단가·보유주식은 그대로 유지됩니다.

실제 증권 계좌 잔고와 계산기 잔여자본이 맞지 않을 때 (예: 쿼터매도 수익 반영 등) 사용합니다.

---

## 데이터 저장 위치

모든 데이터는 **브라우저의 로컬 스토리지**에 자동 저장됩니다.  
인터넷 연결 없이 동작하며, 브라우저를 닫아도 데이터는 유지됩니다.

> 브라우저 캐시/데이터를 초기화하면 기록이 삭제됩니다.  
> 중요한 거래 내역은 별도로 메모해두는 것을 권장합니다.

## T값 계산 원리

### 일반모드

| 상황 | T 변화 |
|------|--------|
| 전체 체결 매수 | +1.0 |
| 절반 체결 매수 (별지점 LOC만 체결) | +0.5 |
| 쿼터매도 | × 0.75 |
| 지정가매도 (사이클 종료) | 0으로 초기화 |

### 리버스모드

| 상황 | T 변화 (40분할) | T 변화 (20분할) |
|------|----------------|----------------|
| 매도 후 | × 0.95 | × 0.90 |
| 매수 후 | + (40 − T) × 0.25 | + (20 − T) × 0.25 |

---

## 별지점 계산 공식

| 종목 | 40분할 | 20분할 |
|------|--------|--------|
| TQQQ | `평단 × (1 + (15 − 0.75×T) %)` | `평단 × (1 + (15 − 1.5×T) %)` |
| SOXL | `평단 × (1 + (20 − 1.0×T) %)` | `평단 × (1 + (20 − 2.0×T) %)` |

- T가 **분할수/2 이하** (전반전): 별지점이 평단보다 높음 → 수익 구간에서 쿼터매도
- T가 **분할수/2 초과** (후반전): 별지점이 평단보다 낮음 → 손실 구간에서도 일부 탈출
- **매수점** = 별지점 − $0.01 (LOC 매수 주문가, 매도와 겹침 방지)
